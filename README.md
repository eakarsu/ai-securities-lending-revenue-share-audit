# Securities Lending Revenue-Share Audit

Rebuild securities-lending economics and recover missing borrower spread, collateral income, and contractual revenue share.

**Primary buyer:** Asset owners, custodians, and fund managers. **Evidence:** agency agreements, eligible portfolios, loans, collateral, rebate rates, investment income, borrower fees, indemnification fees, revenue shares, statements, and cash.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Agency agreement library
- Eligible security inventory
- Loan transaction ingestion
- Collateral balance validation
- Borrower fee calculation
- Rebate rate calculation
- Collateral reinvestment income
- Specials premium analysis
- Indemnification fee control
- Revenue share calculation
- Custodian statement audit
- Corporate action treatment
- Exception dispute workflow
- Cash reconciliation
- Program security analytics

Run `./start.sh`, then open <http://127.0.0.1:4670>. API: `5670`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
